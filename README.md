# # My Portfolio

A beginner-friendly, static personal portfolio website built with HTML and CSS. This project showcases my initial learning journey in web development.

## Features
* **Two-Tier Header:** Clean title and navigation section.
* **About Me Section:** Personal introduction and background.
* **Skills Section:** Highlights my foundational technical skills (HTML, CSS, Python, GitHub).
* **Contact Section:** Static, non-interactive contact fields and button layout.
* **Design:** Styled with custom purple headings and bold black body text.

## Built With
* HTML5
* CSS3
